# Changelog - PulseHQ

All notable changes to the **PulseHQ** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-19

### Added
- **Fullstack React + Express Platform**: Complete implementation of PulseHQ AI team management application.
- **Reference Design Faithful Implementation**:
  - Splash Loading Screen with animated sine pulse wave (`Pilse_HQ _Load.png`).
  - Home Dashboard Screen (`Pulse HQ_Dashboard_Home.png`) featuring Manager Brief, 4 Metric Cards with SVG sparklines, AI Insight Panel, interactive Team Workload Rebalancer, and Priority Queue checklist.
  - Analytics & Reports Screen (`Pulse HQ_Analytics&Report.png`) with **Cyan Neon Aesthetics** (`#00F2FE`), period chips (`3D`, `7D`, `Quarter`), SVG interactive productivity trend line chart, team performance matrix, workload distribution bar, and delivery risk heatmap.
  - Team & Meeting Hub Screen (`Pulse HQ_Meeting.png`) with **Purple Neon Aesthetics** (`#D946EF`), hero buttons (`Wire-frames`, `Assumptions`, `Icon`), team directory, and 1:1 sync scheduler.
- **Micro-Interactions**: Bottom navigation bar active tab indicators, hover glow, press scale feedback, and floating top view mode switcher (Phone Frame vs Responsive Desktop Mode).
- **Standardized Copyright Notice**: Subdued, secondary footer copyright notice (`Copyright © 2026 Kaustobh Bhattacharya`) isolated across all views.
- **CI/CD Deployment**: Automated GitHub Actions workflow (`.github/workflows/deploy.yml`) deploying `dist/` to GitHub Pages at `https://Kaustobh.github.io/Pulse-HQ/`.
- **Documentation Package**: Added `README.md`, `DEPLOYMENT.md`, `CONTRIBUTING.md`, and `CHANGELOG.md`.
