# PulseHQ Component Library & Design System

## System Overview
The **PulseHQ Design System** is built on a dark glassmorphism core (`#0A0E17` / `#141C2E`), leveraging CSS Custom Properties for theme tokens, Framer Motion for micro-interactions, and Lucide React for consistent vector iconography.
