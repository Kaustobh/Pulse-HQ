# PulseHQ Case Study Asset Repository

This directory contains visual artifacts, export checklists, and media assets for portfolio case studies.

## Folder Organization
- `screenshots/`: High-resolution UI captures of all screens.
- `before-after/`: Comparative visuals of workload rebalancing state transformations.
- `wireframes/`: Blueprint layout drawings and UI component wireframes.
- `flows/`: User journey maps and navigation diagrams.
- `final-ui/`: Final responsive mobile and desktop screenshots.
- `components/`: Isolated component tokens (buttons, metric cards, navigation bar).
- `audits/`: Heuristic evaluations, competitive analysis, and accessibility audits.
- `research/`: User interviews, manager surveys, and baseline notes.
