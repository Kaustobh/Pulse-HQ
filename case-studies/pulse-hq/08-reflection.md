# 08 — Reflection & Growth: PulseHQ

## 1. What Would I Improve With More Time?
- **Drag-and-Drop for Desktop Mode**: Add optional drag-and-drop task reassignments for desktop viewports while preserving single-click buttons for mobile containers.
- **Live WebSockets Integration**: Connect the Express backend to WebSockets for real-time multi-manager collaboration during sprint retrospectives.
- **Custom Date Picker**: Expand analytics timeframe filter chips (`3D`, `7D`, `Quarter`) to support custom calendar date range selections.

## 2. What Did I Learn?
- **Designing Resilient Edge Architectures**: Learned how to build hybrid API fallback layers (`apiService.js`) that ensure fullstack applications run flawlessly on static edge hosts (GitHub Pages) without server cold-start delays.
- **Multi-Theme Token Management**: Gained deep experience in scoping CSS custom variables across dynamic navigation tabs.

## 3. What This Project Proves About Me
PulseHQ proves I am a **Lead Product Designer & Full-Stack Systems Architect** who can bridge the gap between human-centered UX design, minimal dark design systems, React 19 frontend implementation, and edge deployment CI/CD pipelines.
